These are the steps I took to download and install the latest Node.js version:

curl -sL https://deb.nodesource.com/setup_16.x | sudo -E bash -
sudo apt install -y nodejs

Clone the repository and check out the master branch:
git clone https://github.com/MichMich/MagicMirror

Enter the repository: cd MagicMirror/

Install the application: npm run install-mm

Make a copy of the config sample file: cp config/config.js.sample config/config.js

Start the application: npm run start

I set up rules that shiut the monitor off at night and reboot the system in the morning
crontab -e
#58  6   *   *   *   vcgencmd display_power 1
#59  6   *   *   *   vcgencmd display_power 0
59  6   *   *   *   /sbin/shutdown -r now
0  23   *   *   *   vcgencmd display_power 0

To Fix Display coming back on after reboot:

sudo nano /boot/config.txt
comment out
#dtoverlay=vc4-kms-v3d
